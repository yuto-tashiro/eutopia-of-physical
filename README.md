# 身体のユートピア (Embodied Eutopia)

**情報に埋もれた身体を、問い直す**  
*Beyond data, beyond objectivity—Rediscovering what true health means.*

---

## プロジェクト概要 (Project Overview)

「身体のユートピア」は、AI時代における身体性の価値を再発見し、健康×文化×身体性を融合した新しい健康観を考える構想です。

株式会社HILUCOが運営し、科学的エビデンスと感性を融合させながら、スポーツ、文化、アート、ビジネスなど多岐にわたる領域で活動しています。

---

## コンセプト (Concept)

### なぜ今、身体か

1. **AI時代の身体性**: 情報が溢れる現代だからこそ、代替不可能な「身体」の価値が際立ちます
2. **科学と感性の融合**: スポーツから始まった身体への探求を、文化・アートへの興味とともに深めています
3. **Utopia から Eutopia へ**: 理想郷ではなく、「良き場所」を今ここに。完成された理想を手渡すのではなく、更新し続けることを前提にしています

---

## 立場 (Where We Stand)

- 科学を使う。しかし、科学に人間を還元しない。
- 専門性を使う。しかし、専門家が人を支配しない。
- テクノロジーを使う。しかし、テクノロジーに身体を従属させない。
- 自由を求める。しかし、孤立ではなく共同体へ向かう。
- 身体をより良くする。しかし、「正しい身体」を一つに決めない。

---

## 誰とともにあるか (Who This Is With)

子ども、働く世代、高齢者、そして動物。生きられる身体を持つ存在は、すべてこの共同体の一員です。ここに序列はなく、市場での価値の大きさで並べ替えられることもありません。

## 構造 (Structure)

この構想は三つの層でできています。図はトップページに SVG で直接埋め込んでいます（広い画面は横並び、狭い画面は縦積みに切り替わります）。

| 層 | 役割 |
|---|---|
| 身体のユートピア | 身体を管理する社会ではなく、身体を通して自由に生きられる社会を考える構想 |
| フリーランスセラピスト | 制度と生活世界を越境し、制度の光が届きにくい一隅へ自ら移動する実践者 |
| 株式会社HILUCO | 全体を統括するのではなく、あいだに立ち、関係をつなぎ直し、そこで生まれた知を循環させる媒介者 |

## 活動の3つの柱 (Three Pillars)

### 🔬 Science & Education (科学と教育)
エビデンスに基づいた身体の理解を深め、専門家・一般の方々へ向けた教育活動を展開

### 🎨 Culture & Art (文化と芸術)
日本文化に根ざした健康観を再認識するとともに、世界各国の文化に合わせた健康観を理解。質的アプローチとアートの融合を探求

### 🤝 Social & Well-being (社会とウェルビーイング)
コミュニティ形成支援、企業の健康経営サポート、ソーシャルデザインを通じて、誰もが自分の身体で居られる環境をつくる

## 技術スタック (Tech Stack)

- **HTML5**: セマンティックな構造
- **CSS3**: 伝統的な日本の色彩（生成り、墨色、朱色など）を使用したデザインシステム
- **JavaScript**: スクロールアニメーション、Intersection Observer API
- **フォント**: Noto Serif JP (日本語) / Cormorant Garamond (英語)
